#Electricity bill calculator

##Description
This program calculates the total electricity bill.

##Version 1 - Original code without input validation

-Input: customer name, previous meter reading, current meter reading, rate

-Process:
calculate consumption by subtracting current and previous meter reading, total bill will equal to consumption times rate

-Output:
customer name, electricity consumption, total bill

##Version 2 - Updated Final code with input validation

-Input: customer name, previous meter reading, current meter reading, rate

-Process:
calculate consumption by subtracting current and previous meter reading, total bill will equal to consumption times rate

-Output:
customer name, electricity consumption, total bill
